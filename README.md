# pratica-c-sharp
Compilado de exercicio para treino de c#.
Esse repositório contém uma diversidade de exercicios, com seus enunciados no arquivo program.cs.

Favor, caso entre na pasta do exercicio, clique na pasta com seu título, depois você uma outra pasta com o mesmo nome, clique nela novamente, após isso você será direcionado para o local do arquivo program.cs e arquivos de classe.
