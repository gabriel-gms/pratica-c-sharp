# pratica-c-sharp
Compilado de exercicio para treino de c#.
Esse repositório contém uma diversidade de exercicios, com seus enunciados no arquivo program.cs de cada repositório.

Favor, caso queira ver o exercicio, clique na pasta com o título do exercício, assim você será levado para um outro local que tem mais uma pasta com o nome do exercicio de novo, clique nela novamente, após isso você será direcionado para o local do arquivo program.cs e arquivos de classe.

Ficando assim o caminho: `pasta-com-nome-exercicio/pasta-com-nome-exercicio/Program.cs`
